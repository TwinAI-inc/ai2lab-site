How This Tool Works

Purpose

This microscope shows you EXACTLY how the Bellman equation calculates each state's value during policy evaluation.

Steps to Use

1. Click any state in the left grid to examine it under the microscope

2. The microscope shows that cell (yellow) and its neighbors (blue)

3. Click "Run Sweep" to perform one iteration of policy evaluation

4. Watch how neighbor values determine the new value

The Math

V(s) = Reward + γ × average(neighbor values)

Terminal states (corners) have fixed goal/penalty values
