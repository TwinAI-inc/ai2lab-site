Understanding MDPs, Returns & Bellman Equations

Transition Probabilities

Core Concept: Stochastic dynamics

p(s',r|s,a) = Pr{St=s', Rt=r | St-1=s, At-1=a}

• Main: Action succeeds

• Side: Lateral slips

Return Gt

Cumulative Reward: Total discounted

Gt = Rt+1 + γRt+2 + γ²Rt+3 + ...

• γ: Discount factor

• Future value decay

Bellman Equation

Value Function: Recursive definition

V(s) = R(s) + γ max V(s')

• Immediate + Future

• Bootstrap values
