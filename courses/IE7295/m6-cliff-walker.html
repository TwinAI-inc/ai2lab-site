Understanding SARSA vs Q-Learning

SARSA (On-Policy)

Core Concept: Learns from actual behavior

Q(s,a) Q + α[r + γQ(s',a') - Q]

• Uses action it WILL take (a')

• Includes exploration risk

• Results in safer paths

Q-Learning (Off-Policy)

Core Concept: Learns optimal policy

Q(s,a) Q + α[r + γ max Q(s',a) - Q]

• Uses BEST action (max)

• Ignores exploration

• Finds optimal path

Key Difference

The Cliff Problem:

• SARSA: Avoids cliff edge

• Q-Learning: Walks along cliff

• Trade-off: Safety vs Optimality
