Golden Gate bonds
The bridge district sold $35M of bonds in 1932. The board wants to know: which year will the bonds be fully retired from toll receipts?
Which method?click
DPBP discounted payback period
The question is about the calendar, not whether the project is profitable. You want the first year the cumulative discounted cash flow turns non-negative.
DPP ≈ 34 yr — the bonds were actually retired in 1971.

Nobel Foundation endowment
Alfred Nobel wants to fund five prizes every year, forever, from interest only. How big a corpus does he need to leave?
Which method?click
CC capitalized cost
An infinite, level annual payment drawn from a permanent fund is the textbook setup for capitalized cost.
CC = A / i = 1.55M SEK / 0.05 = ~31M SEK — exactly Nobel's bequest.

Retirement target
A 35-year-old wants to know: if I save $500/month at 6% return, what will I have at age 65?
Which method?click
FW future worth
The question rolls cash flows forward to a specific future date — classic FW. Use (F/A, i, n) to convert the savings stream into a single future amount.
F = $500 · (F/A, 0.5%, 360) ≈ $502 k at age 65.

Buy or lease
Buy a building for $1.2M today, or lease it for $130k/yr for 12 years. Same useful life either way. Which costs less in today's dollars?
Which method?click
PW present worth
Two streams, same horizon, different shape. Pull both back to today's dollars and pick the smaller cost (or larger benefit).
PW_buy = $1.2M · PW_lease = 130 · (P/A, 8%, 12) ≈ $980 k.

Two mines, different lives
Project A runs 5 years, Project B runs 8 years. Both clear MARR by PW. Which generates more income per year of operation?
Which method?click
AW annual worth
Different lives, no LCM headache: AW puts each alternative on a per-year basis, directly comparable. No need to repeat projects, no need to find LCM.
AW = PW · (A/P, i, n). Pick the alternative with the larger AW.

Bridge maintenance forever
A city needs $200k/yr indefinitely to maintain its bridge. They want to set up a permanent endowment today instead. How big?
Which method?click
CC capitalized cost
A perpetual annual outflow means CC = A / i. The fund's interest pays the maintenance; the principal never gets touched.
CC = $200 k / 0.05 = $4 M endowment today.

Equipment A vs B
Both machines have positive PW. Machine B costs more but earns more. Does the extra cost of B earn back more than the MARR?
Which method?click
IRR incremental rate of return
For mutually exclusive choices on a rate-of-return basis, form Δ(B−A) cash flows and find the IRR on the increment. Accept B if IRRΔ > MARR.
Reject the bigger investment if IRRΔ < MARR — even when both projects pass standalone.

R&D project accept/reject
Engineering proposes a $4M project with seven years of forecasted cash inflows. Should we accept it at 10% MARR?
Which method?click
PW present worth
Single project, single horizon, accept-or-reject. The clean test is PW > 0 at the MARR. Anything else (DPP, IRR) is overlay diagnostics.
If PW(10%) > 0 → accept. PW < 0 → reject. No comparison needed.
