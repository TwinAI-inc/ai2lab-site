THE PROBLEM

Why ANOVA?

THE SCENARIO

You have 3 or more groups and want to know if their means differ significantly.

For example: Do three machines produce different output rates? Do four teaching methods yield different test scores?

WHY NOT MULTIPLE T-TESTS?

With 3 groups, you need 3 pairwise t-tests. Each at $\alpha = 0.05$ inflates your overall error rate:

$$\alpha_{\text{overall}} = 1 - (1 - \alpha)^k$$

For $k=3$ comparisons:

$$\alpha_{\text{overall}} = 1 - (0.95)^3 \approx 0.143$$
⚠
TYPE I ERROR INFLATION

Instead of a 5% chance of a false positive, you now have a 14.3% chance. With 10 groups and 45 comparisons, it jumps to ~90%! ANOVA solves this with a single, unified test.

CORE CONCEPT

The ANOVA Idea

Total Variation = Between-Group Variation + Within-Group Variation

$$SS_T = SS_B + SS_W$$
📈
SST (TOTAL)

How much do all observations vary from the grand mean?

$$SS_T = \sum_{i}\sum_{j}(x_{ij} - \bar{x}_{\cdot\cdot})^2$$
↔
SSB (BETWEEN)

How much do group means vary from the grand mean?

$$SS_B = \sum_{i} n_i(\bar{x}_{i\cdot} - \bar{x}_{\cdot\cdot})^2$$
⇵
SSW (WITHIN)

How much do observations vary within each group?

$$SS_W = \sum_{i}\sum_{j}(x_{ij} - \bar{x}_{i\cdot})^2$$
💡

Key insight: If the between-group spread is much larger than the within-group spread, the groups are likely different.

THE TEST STATISTIC

The F-Statistic

FORMULA
$$F = \frac{MS_B}{MS_W} = \frac{SS_B \;/\; (k-1)}{SS_W \;/\; (N-k)}$$
$k$ = number of groups
$N$ = total observations
$MS_B$ = mean square between
$MS_W$ = mean square within
📚

Under $H_0$, $F$ follows the F-distribution with $(k{-}1,\; N{-}k)$ degrees of freedom.

KEY PROPERTIES
  • ✓ $F \geq 0$ always
  • ✓ Right-skewed distribution
  • ✓ Large $F$ = evidence of difference
  • ✓ $F \approx 1$ under $H_0$
DECISION RULE

Reject $H_0$ if $F > F_{\alpha,\;k-1,\;N-k}$

Or equivalently: reject if p-value $< \alpha$

BEFORE YOU TEST

ANOVA Assumptions

Independence

Observations within and across groups are independent of each other.

If violated: Use repeated measures ANOVA or mixed-effects models.

Normality

Each group's data is approximately normally distributed.

If violated: Use Kruskal-Wallis test (non-parametric alternative).

Equal Variance

All groups have similar variance $\sigma^2$ (homoscedasticity).

If violated: Use Welch's ANOVA or transform data.

🔎

Pro tip: ANOVA is robust to mild violations of normality (especially with balanced group sizes). Check with Levene's test for equal variance and Shapiro-Wilk for normality.

STEP BY STEP

Example Solution

STEP 1 — GROUP MEANS
$\bar{x}_A = 24.2$,   $\bar{x}_B = 30.0$,   $\bar{x}_C = 25.0$
Grand mean: $\bar{x}_{\cdot\cdot} = \frac{24.2 + 30.0 + 25.0}{3} = 26.4$
STEP 2 — SUM OF SQUARES
$SS_B = 5(24.2{-}26.4)^2 + 5(30.0{-}26.4)^2 + 5(25.0{-}26.4)^2$
$\phantom{SS_B} = 5(4.84) + 5(12.96) + 5(1.96) = \mathbf{98.8}$

$SS_W = \sum\text{(within-group deviations}^2\text{)}= \mathbf{27.6}$

$SS_T = 98.8 + 27.6 = \mathbf{126.4}$

AFTER ANOVA

Post-Hoc: Tukey's HSD

THE PROBLEM

ANOVA tells you "at least one mean is different" but does not tell you which ones differ.

Tukey's Honestly Significant Difference (HSD) compares all pairs while controlling the family-wise error rate.

FORMULA
$$HSD = q_{\alpha,\;k,\;N-k} \cdot \sqrt{\frac{MS_W}{n}}$$

$q$ = Studentized Range statistic, $n$ = observations per group

Rule: If $|\bar{x}_i - \bar{x}_j| > HSD$, then groups $i$ and $j$ differ significantly.

APPLYING TO OUR EXAMPLE

With $q_{0.05,\;3,\;12} \approx 3.77$, $MS_W = 2.3$, $n = 5$:

$$HSD = 3.77 \cdot \sqrt{\frac{2.3}{5}} = 3.77 \times 0.678 = 2.56$$
PAIRWISE COMPARISONS
✗ $|A - B| = |24.2 - 30.0| = 5.8 > 2.56$ → Significant
✓ $|A - C| = |24.2 - 25.0| = 0.8 < 2.56$ → Not significant
✗ $|B - C| = |30.0 - 25.0| = 5.0 > 2.56$ → Significant

Machine B is significantly faster than both A and C.

WRAP-UP

Key Takeaways

🎯
When to Use

Comparing means of 3+ groups with a single continuous outcome variable.

⚖
The Logic

Partition total variation into between vs within. Large ratio = significant.

✅
The Workflow

Check assumptions → Run ANOVA → If significant, do post-hoc tests.

F-STATISTIC
$F = \dfrac{MS_B}{MS_W}$
TUKEY'S HSD
$HSD = q \cdot \sqrt{\dfrac{MS_W}{n}}$
