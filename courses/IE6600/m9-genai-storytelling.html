GenAI Workshop: Data Storytelling with Interactive Narratives

Module 09

GenAI Workshop: Data Storytelling

Creating Interactive Narratives with Claude AI
Prof. Mohammad Dehghani | Northeastern University

Workshop Overview

Duration

4 Progressive Stages (4 Weeks)

Tools

Claude AI, Flourish.studio, Datawrapper

Outcome

Professional data-driven narrative web pages

How This Workshop Works

  1. Prepare Your Data: Create visualizations in Flourish.studio or Datawrapper
  2. Copy Embed Codes: Get the iframe embed codes from your visualization platforms
  3. Take Screenshots: For Stage 3, capture a screenshot of your main chart for data cards
  4. Use Claude AI: Copy the structured prompts and paste them into Claude
  5. Answer Claude's Questions: Claude will ask multiple-choice questions about your preferences
  6. Provide Your Materials: Share embed codes, screenshots, and any other content
  7. Iterate & Improve: Refine your work through each progressive stage
Important Requirements:
• Stage 1: Have 1 embed code ready
• Stage 2: Prepare 3 related visualizations (tells a story)
• Stage 3: Need 4-6 embeds + screenshot of main chart
• Stage 4: Gather 6-10 embeds + any supplementary content

Claude will ask you design questions first, then request your materials.

Learning Objectives

Stage 1

Master basic HTML structure and embed your first visualization with personal style

Stage 2

Build multi-section narratives with Feather Icons and professional layouts

Stage 3

Add interactivity, create data cards from screenshots, and engage users

Stage 4

Create publication-ready stories worthy of major data journalism outlets

Key Skills You'll Develop:
• Prompt engineering for AI-powered web development
• Data visualization integration and storytelling
• Responsive design and user experience
• Professional web development practices

Prompt Engineering Tips

  • Be Specific: Include exact hex colors, dimensions, spacing
  • Iterate: Use "modify the above to..." for refinements
  • Reference Examples: "Make it similar to [website] but with..."
  • Debug Systematically: "The embed isn't showing, please fix..."
  • Save Progress: Keep copies of successful prompts
