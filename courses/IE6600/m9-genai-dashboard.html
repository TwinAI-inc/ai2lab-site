How This Lab Works
  1. Find a dashboard you love: browse Dribbble, Pinterest, or Behance. Save a screenshot.
  2. Download the 3 CSV files (provided with this lab). You use one per stage:
Prompt 1New Claude chat + coffee_countries.csv + screenshot → skeleton + KPIs
Prompt 2Same chat + coffee_market_annual.csv → adds charts
Prompt 3Same chat + coffee_prices_monthly_2024.csv → adds interactivity
Prompt 4Same chat, no new data → final polish
Stay in one Claude conversation for all 4 prompts. Claude remembers your work. Each prompt asks new personalization questions. Every student's dashboard will be unique.
Step 0: Find Your Style Reference Search for a dashboard design screenshot to use as your style template:

  • Pinterest: search "modern web dashboard design"

Save as PNG or JPG. Attach alongside Prompt 1 so Claude matches that design's style.

Debugging Tips
  • Dark mode breaks chart colors → "Chart text and grid lines are invisible in dark mode, fix contrast"
  • Filters don't update → "The filter buttons aren't calling chart.update() with new data"
  • Hover mini-chart missing → "The KPI hover popup with trend chart is not showing"
  • Tab underline doesn't slide → "Make the tab indicator translateX to the active button position"

Resources & Tips

Prompt Engineering Tips for Dashboards
  • Be specific about layout: "2x2 grid" beats "arrange nicely"
  • Name your colors: give hex codes, not just "blue"
  • Iterate, don't restart: stay in the same chat and say "upgrade this"
  • Debug with Claude: paste broken code and describe what's wrong
  • Ask for alternatives: "Show me 2 different color schemes"

Common Issues & Fixes
  • Chart not rendering: Check that the Chart.js CDN script tag is before your chart code
  • Layout overflow on mobile: Tell Claude "fix horizontal scroll on mobile"
  • Dark mode breaks charts: "Update Chart.js font and grid colors for dark mode"
  • Export captures blank: Tell Claude to "add a delay before capture"
