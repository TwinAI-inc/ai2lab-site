Stage 1: Your First AI-Generated Chart

Begin your journey by creating a clean, professional bar chart. This foundation teaches you how to structure prompts effectively and generate publication-ready visualizations.

What You'll Master:

  • Structuring data in your prompts
  • Specifying chart dimensions and styling
  • Adding interactivity (hover effects)
  • Making charts responsive
  • Professional color schemes

  • Smooth transitions between states

Dashboard Architecture:

  • Global filters affecting all charts
  • Professional dashboard aesthetics
  • Performance optimization

4. Bottom Right: Scatter plot showing Investment vs ROI correlation

DATA (CSV format):

GLOBAL CONTROLS (at top of dashboard):

Create an innovative, story-driven visualization that guides viewers through the AI adoption journey.

CONCEPT: "The AI Revolution Timeline"
Design a horizontal scrolling timeline that tells the story of AI adoption from 2019 to 2024.

VISUALIZATION REQUIREMENTS:
- Create a custom "journey map" visualization
- Each year is a "milestone" on the timeline with:
  * Animated circular progress indicator for adoption rate
  * Investment amount as particle effects (more particles = more investment)
  * Key innovation for that year as an icon
  * GenAI emergence shown as a branching path (2022 onwards)

DATA (Complete integrated dataset):
[PASTE THE COMPLETE DATASET CSV HERE - includes all categories: Yearly Trend, Industry, Monthly, and Regional data]

STORYTELLING ELEMENTS:
- Opening animation: "The AI Transformation" title sequence
- Narrative text that appears as user scrolls:
  * 2019: "The Beginning - Early Adopters"
  * 2020: "Pandemic Acceleration"
  * 2021: "The Mainstream Moment"  
  * 2022: "GenAI Emerges"
  * 2023: "The ChatGPT Effect"
  * 2024: "Universal Adoption"

ADVANCED ANIMATIONS:
- Parallax scrolling effects
- Numbers counting up as they appear
- Smooth morphing between chart types
- Particle systems for investment visualization
- Glowing pulse effects for milestones
- SVG path animations for connections

INTERACTIVE FEATURES:
- Click any milestone for detailed breakdown
- Mini dashboard appears with that year's full stats
- Compare mode: select 2 years to see side-by-side
- Industry filter: highlight specific industry journey
- Playback controls: auto-play through the timeline

PROFESSIONAL POLISH:
- Loading animation with progress bar
- Smooth 60fps animations using requestAnimationFrame
- Mobile swipe gestures for timeline navigation
- Keyboard shortcuts (arrow keys, spacebar for play/pause)
- Full-screen mode option
- Share buttons with custom OpenGraph meta tags
- Accessibility: ARIA labels and keyboard navigation

EXPORT OPTIONS:
- "Export as Image" button for each visualization state
- "Get Embed Code" with responsive iframe wrapper
- "Download Data" to get the processed dataset

The final output should feel like an interactive article from the New York Times or Bloomberg.
