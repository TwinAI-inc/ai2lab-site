The Statistical Paradox

In 1973, Francis Anscombe created four datasets that would forever change how we approach data analysis. These datasets share identical statistical properties yet tell completely different stories when visualized.

Key Insight: All four datasets have the same mean (x̄=9, ȳ=7.5), same variance, same correlation (r=0.816), and same regression line (y = 3.00 + 0.500x).

Visual Pattern Analysis

Dataset I

Pattern: Standard linear relationship
Key Feature: Points scattered randomly around regression line
Use Case: Perfect for linear regression analysis

Dataset II

Pattern: Perfect parabolic curve
Key Feature: Non-linear quadratic relationship
Warning: Linear regression completely inappropriate

Pattern: Linear with outlier
Key Feature: Single point at (13, 12.74) distorts statistics
Impact: Outlier pulls regression line upward

Danger: Single point determines entire regression
