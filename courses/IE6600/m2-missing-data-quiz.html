What to take away

Measure the gap before you fix itCount the blanks per column and turn them into a percentage. Four missing values and forty percent missing are different problems.
Median for numbers, mode for categoriesThe median survives outliers, the mode is the least surprising guess. Neither is a rule, both are a default you can defend.
A gap never announces itself on a chartA zero-filled bar, a bar built on half the rows and a line drawn straight through a missing month all look like measured data.
Ask whether the gap has a shapeMissing at random is noise. Missing because something broke is a pattern, and filling it erases the very thing worth knowing.
Write down what you didEvery fill and every dropped row changes the answer. The note costs one line and is the difference between a result and a claim.
