All roads lead to Rome

The original graph

Cities were the nodes, roads were the edges, and any message could be routed along fixed, reliable paths. Build it once, and traffic flows the same way every time. That is a graph.

The crew that moved an empire

The original crew

A galley moved only when scores of rowers pulled together, each with a role, coordinated by a process: a drummer set the pace, an officer called the goal. No fixed map, just a team that adapts as one. That is a crew.

Landscape
AI agents vs Agentic AI
AI agent

A single agent, an LLM with tools, for task-specific automation.

  • One agent plus tool use and reasoning
  • Limited autonomy, no persistent memory
  • Support, scheduling, summarization
Agentic AI

Many agents, coordinated, with memory and shared goals.

  • Multi-agent collaboration and delegation
  • Dynamic task decomposition, persistent memory
  • Research, robotics, decision support
Today's frameworks build the right side: LangGraph and CrewAI orchestrate many agents. Source: Sapkota, Roumeliotis & Karkee (2025), "AI Agents vs. Agentic AI: A Conceptual Taxonomy," Information Fusion · arXiv:2505.10468

The two frameworks

Two philosophies of control: a graph you draw, and a crew you assemble.

From Graph to Crew
Mental model
Two ways to think about orchestration
Graph, a state machine you draw
  • Explicit control flow: nodes, edges, branches, loops
  • A shared State object updates at each node
  • Strength: control, reliability, branching and loops
Crew, a team you assemble
  • Roles, the agents, plus tasks to complete
  • A process coordinates who acts and when
  • Strength: speed, role decomposition, delegation
Bottom line: Graph trades convenience for control. Crew trades control for convenience.
From Graph to Crew6 / 14
Framework one · the Graph world
LangGraph: nodes, edges, state
  • State: a typed shared object
  • Node: a function that updates State
  • Edge: a fixed step in the flow
  • Conditional edge: routing decided at runtime
  • Cycles are allowed, so loops are first class
  • Built-ins: checkpointers, human-in-the-loop

If you can draw the flowchart, you can build the graph.

# scout to stats to write, with a loop back g = StateGraph(State) g.add_node("scout", scout) g.add_node("stats", stats) g.add_node("write", write) g.add_edge("scout", "stats") g.add_conditional_edges( "stats", need_more, {"yes": "scout", "no": "write"}) app = g.compile()
From Graph to Crew7 / 14
Framework two · the Crew world
CrewAI: agents, tasks, crew
  • Agent: role, goal, backstory, tools, LLM
  • Task: description plus expected output
  • Crew: the agents plus the tasks
  • Process: sequential or hierarchical
  • Built-ins: tools, memory, Flows

If you can write the job descriptions, you can build the crew.

# four roles, run in sequence scout = Agent(role, goal, backstory, tools) task1 = Task(description, expected_output, agent=scout) crew = Crew( agents=[scout, stats, tactics, writer], tasks=[task1, task2, task3, task4], process="sequential") result = crew.kickoff()
